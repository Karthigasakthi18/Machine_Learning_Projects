# Machine Learning Projects

This repository contains three machine learning and data analytics projects developed using Python. These projects demonstrate skills in data preprocessing, predictive modeling, and model deployment.

## Projects

### 1. Sales Forecasting
**Description:**
Developed a machine learning model to predict future sales using historical sales data. Performed data preprocessing, visualization, and forecasting using Python.

**Technologies:**
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

### 2. Multiple Linear Regression
**Description:**
Built a multiple linear regression model to analyze relationships between multiple independent variables and predict target values accurately.

**Technologies:**
- Python
- Pandas
- Scikit-learn

---

### 3. Flask Model Deployment
**Description:**
Developed a Flask web application to deploy a trained machine learning model, allowing users to provide inputs and receive predictions through a simple interface.

**Technologies:**
- Python
- Flask
- HTML
- Machine Learning
